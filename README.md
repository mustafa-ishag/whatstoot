# 🤖 WhatsToot Bot

بوت واتساب ذكي ومستقل مبني بالكامل باستخدام **Node.js** لمساعدة فرق العمل في إدارة وتنظيم صور أوامر العمل الخاصة بالمقاولات. يقوم البوت بالتقاط الصور المرسلة في مجموعات الواتساب، يربطها برقم أمر العمل، ويرفعها مباشرة وبشكل منظم إلى **Synology NAS** أو **Google Drive**.

---

## 🌟 المميزات

- 🚀 **تطبيق مستقل:** يعمل بالكامل بـ Node.js فقط، لا حاجة لـ PHP أو سيرفرات ويب معقدة مثل Apache/Nginx.
- 📁 **تنظيم ذكي للملفات:** يستخرج أرقام أوامر العمل تلقائياً من الرسائل النصية ويربط صور نفس المستخدم بها.
- ☁️ **دعم سحابة مزدوج:** إمكانية الرفع إلى `Synology NAS` (عبر File Station API) أو `Google Drive`.
- 📊 **لوحة تحكم (Dashboard):** واجهة ويب بسيطة لمتابعة الرفعات، الأخطاء، وإحصائيات البوت.
- 🔄 **نظام طابور متقدم:** طابور لمعالجة الصور لتجنب حظر واتساب، مع نظام إعادة محاولة للأخطاء العابرة (Retries).
- 🧠 **منع التكرار (Duplicate Checker):** يحسب بصمة الصورة (SHA-256) لمنع رفع نفس الصورة مرتين لنفس أمر العمل.

---

## 📋 المتطلبات الأساسية

- **نظام التشغيل:** Linux (Ubuntu/Debian) أو Windows.
- **Node.js:** إصدار 18 أو أحدث (يُفضل 20 LTS).
- **RAM:** لا يقل عن 512 ميجابايت.
- (اختياري) مساحة على Synology NAS أو حساب Google Drive للربط.

## 🚀 التثبيت والتشغيل المحلي (للتطوير أو الويندوز)

### 1. استنساخ المشروع وتثبيت التبعيات
```bash
git clone https://github.com/mustafa-ishag/whatstoot.git
cd whatstoot
npm install
```

### 2. إعداد ملف البيئة
قم بنسخ ملف الإعدادات الافتراضي:
```bash
cp .env.example .env
```
افتح ملف `.env` وقم بتعديل إعدادات التخزين (رابط الـ NAS، اسم المستخدم، الباسورد، إلخ).

### 3. التشغيل
```bash
# للمشاهدة العادية
node server.js

# في الويندوز يمكنك فقط النقر المزدوج على
# start-bot.bat
```
عند التشغيل لأول مرة، سيظهر لك **QR Code** في شاشة سطر الأوامر (Terminal). امسحه باستخدام تطبيق الواتساب بجوالك لربط البوت.

## 🌍 النشر على خادم حقيقي (VPS - Ubuntu)

إذا أردت تشغيل البوت على سيرفر ليظل يعمل 24/7، اتبع الخطوات التالية كصلاحيات الجذور (`root`):

### 1. التثبيت السريع للبيئة
```bash
# تثبيت Node.js 20
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs
```

### 2. تجهيز المشروع
```bash
cd /opt
sudo git clone https://github.com/mustafa-ishag/whatstoot.git
cd whatstoot
sudo cp .env.example .env
sudo nano .env
```
*(عدل القيم في ملف .env ثم احفظ بالضغط على Ctrl+X ثم Y ثم Enter).*

### 3. تشغيل سكربت النشر الآلي
لقد جهزنا سكربت سيقوم بكل شيء: تثبيت الحزم، إنشاء مستخدم خاص، تشفير المجلدات، وإنشاء خدمة للنظام (`systemd`).
```bash
sudo chown -R $USER:$USER /opt/whatstoot
sudo bash deploy/deploy.sh
```

### 4. تسجيل دخول الواتساب
بعد انتهاء السكربت، سيكون البوت يعمل في الخلفية بانتظار مسح الباركود:
```bash
# عرض السجلات لمشاهدة الباركود ومسحه
sudo journalctl -u whatstoot -f
```
**(اضغط `Ctrl+C` للخروج من السجلات بمجرد أن يظهر "✅ واتساب جاهز!").**

## ⚙️ أوامر إدارة البوت (في الـ VPS)

| الأمر | الوصف |
|-------|-------|
| `sudo systemctl restart whatstoot` | إعادة تشغيل البوت |
| `sudo systemctl stop whatstoot` | إيقاف البوت مؤقتاً |
| `sudo systemctl status whatstoot` | التأكد من عمل البوت |
| `sudo journalctl -u whatstoot -f` | مراقبة سجلات البوت الحية (الأخطاء والأنشطة) |

## 📱 أوامر البوت في الواتساب

يمكنك إرسال هذه الأوامر في أي مجموعة يتواجد فيها البوت (يجب أن يتم تفعيل البوت في تلك المجموعة):

- `!status` : يعرض حالة البوت، عدد الصور في الطابور، وعدد الأخطاء.
- `!reset 123456789` : يمسح سجل أمر العمل المحدد من قاعدة البيانات، مفيد إذا أردت رفع نفس الصور مرة أخرى وتم حظرها بسبب "منع التكرار".
- `!move 1111 2222 5` : نقل آخر 5 صور من أمر العمل `1111` إلى أمر العمل `2222`.
- `!help` : استعراض قائمة الأوامر.
